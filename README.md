
# 💰 Expense Tracker - Smart Expense Manager

Track expenses by typing OR just scanning a receipt. The app auto-fills the form, tracks your budgets, and generates a monthly PDF report.

Built with Kotlin + Jetpack Compose for Android.

### 🎬 Demo Video
[Watch 60-sec Demo](https://github.com/user-attachments/assets/f5364147-4038-4288-975f-e955e9562923)

### ✨ Key Features
- **📸 Receipt Scanner:** Scan a receipt with Camera / Gallery -> ML Kit auto-fills amount, date & store
- **💰 Smart Budgets:** Set budget per category e.g. Food - R200. Copy last month's budget in 1 tap
- **📊 Visual Insights:** Bar Chart + Pie Chart in Budget Overview
- **⚠️ Overbudget Alerts:** Get notified when you go over budget (WorkManager)
- **📄 PDF Reports:** Generate a monthly financial report as PDF
- **🔍 Search & Filter:** Search expenses, filter by category with count chips
- **💱 Currency Settings:** Change currency to ZAR, USD, EUR, etc.
- **🔐 Auth:** Register / Login with Firebase Auth

### 🛠️ Tech Stack
- **Language / UI:** Kotlin, Jetpack Compose, Material 3
- **Architecture:** MVVM, Hilt for Dependency Injection, Coroutines
- **Local DB:** Room
- **Backend:** Firebase Auth, Firestore, Firebase Storage, Vertex AI
- **AI / Vision:** ML Kit Text Recognition, CameraX, Coil
- **Background:** WorkManager

### 🚀 How To Run
1. Clone the repo: `git clone https://github.com/owenchikom-star/expense-tracker-proper.git`
2. Open in Android Studio
3. Add your `google-services.json` for Firebase
4. Run on Emulator / Physical Device (Android 8.0+)
